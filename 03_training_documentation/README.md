# Training Documentation

This section presents the KVS Cash & Carry Odoo workflow as an eight-step operating manual built around the daily work of a non-technical grocery owner: capture the product, configure it in Odoo, order it, receive it, label it, sell it, replenish it, and control stock.

The instructions use practical grocery-business language, annotated screenshots, and step-level checkpoints. Odoo app, menu, field, status, and button names remain in English in every edition so the written guidance matches the live interface.
